# Returning items

## Which orders can be returned
You can ask to return items of a delivered order within the return window. The window starts when the order is
delivered; its length is set by the platform's admins, and the order page shows whether an order can still be returned.
After the window has passed, a return can no longer be requested. You can return any items and quantities that were not
returned before, with one open return request per order. For restaurant orders the same thing is called "report a
problem".

## How to ask for a return
Open the delivered order and choose the items to return, with a reason: damaged, wrong item, missing, quality, or other,
and a note if you like. The assistant can also prepare the request for you; you confirm it in the app.

## Who decides
The store or restaurant approves or rejects the return, with a comment. If it does not decide in time, the platform's
admins decide instead. The status goes from requested to approved and then refunded, or to rejected.

## How much is refunded
The server works out the refund: each returned item's share of what you paid for it, minus its share of any coupon
discount. The delivery fee is refunded too when everything left in the order is returned. Nobody in the chat can
promise an amount before the store decides. The refund of an approved return is paid automatically to the same payment
method.

## Pickup
The app does not arrange a pickup of returned items, and the return request does not ask you to send or bring the
items back. If you are not sure what to do with them, raise a complaint and the support team will help.
